# E-Commerce Sales Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on an E-Commerce sales dataset using Python.

The goal is to analyze sales, profit, products, customers, categories, discounts, and regional performance.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

- Data cleaning
- Missing value analysis
- Duplicate detection
- Descriptive statistics
- Sales analysis
- Profit analysis
- Category analysis
- Product analysis
- Monthly sales analysis
- City and state analysis
- Outlier analysis
- Correlation analysis
- Data visualization

## 📈 Visualizations

The project includes:

- Category-wise sales charts
- Monthly sales trend
- Age distribution
- Sales vs discount analysis
- Correlation heatmap

## 🔍 Key Insights

- Analyzed sales performance across different product categories.
- Identified monthly sales trends.
- Compared sales across cities and states.
- Analyzed the relationship between sales, profit, and discounts.
- Examined customer age and rating patterns.
